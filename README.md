# Green Lantern — Reading Order

A Pull List reading-order tracker for Green Lantern, built on Pull-List-template v3.

- **Complete coverage** runs from Green Lantern: Rebirth (2004) to today: the core books, the Corps
  and the emotional-spectrum spin-offs.
- **Events** are built to the Essential/Complete Event Standard.
- **Before 2004**, a curated set of landmarks.
- **Out-of-continuity tales** are on an Elseworlds track (ALT).

Absolute Green Lantern is not here; it is in the Absolute tracker.

## Where things are
- **Rules for every session:** `CLAUDE.md`.
- **Where the work stands, and where the next step begins:** `PROGRESS.md`.
- **The approved plan:** `PLAN.md`.
- **The template's conventions:** `BUILD-NOTES.md`.
- **Moving a live tracker onto v3:** `MIGRATING.md`.
- **The Skill** sessions load: `.claude/skills/comic-tracker-build/SKILL.md`.

## The loop
```
npm ci
python3 tools/build.py            # dataset.json → data.js, sw.js, manifest.json, workbook.xlsx
python3 tools/verify_gate.py      # the pinned verify.py + the order the app shows
node test/run.js                  # jsdom harness — report the assertion count
npm run test:layout               # real Chromium — report the count
python3 tools/build.py --check    # generated files fresh
```

- **The master data** is `dataset.json` with its per-era files (`data/README.md`), and the canonical events in `events/`.
- **Generated by the build:** `data.js`, `sw.js`, `manifest.json` and `workbook.xlsx`. Never hand-edit them.
